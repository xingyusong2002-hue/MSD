Welcome to Chromatic Echoes

A few seconds of context before you step inside

You are about to enter the Dead Room — an anechoic chamber that absorbs almost all sound. Your voice will sound flat. Your claps will not echo. Even silence will feel different.

Inside, you will become a colour. When you make sound, the room will paint with it on the screen at the centre. Working with the others, you'll learn what loudness, rhythm, and silence look like.

If a phone can't reach the URL
  • Check the phone is on the same Wi-Fi / hotspot as this laptop.
  • Use the recommended URL above, not a VirtualBox / vEthernet / Bluetooth address.
  • Windows Firewall may need to allow Node.js on Private networks.
  • Disable any VPN temporarily.
  • If still stuck, switch to a phone hotspot (more permissive than corporate Wi-Fi).
If the page opens but the microphone doesn't work

Mobile browsers require an HTTPS URL for microphone access. Run an HTTPS tunnel on this laptop and share the resulting https://… URL:

cloudflared tunnel --url http://localhost:8080
ngrok http 8080
